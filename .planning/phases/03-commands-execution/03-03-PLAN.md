**Cancel sentinel polling (JOB-06, D-06):**
Set up a `setInterval(1000)` that checks `existsSync(getCancelPath(statePath, jobId))`. On detection:
1. Clear the interval
2. Set a `cancelled` boolean flag to `true`
3. Log `logger.warn('Cancel sentinel detected')`
4. Note: The adapter execution promise will resolve/reject naturally. The `cancelled` flag prevents writing `completed`/`failed` status after cancellation. The parent companion's cancel command already wrote `cancelled` status to the job metadata.
5. Call `process.exit(0)`

Important: Worker does NOT need to kill the adapter child process itself in this implementation because `spawnWithTimeout` in the runtime manages the child process lifecycle. When the worker process exits, the child process will be orphaned and cleaned up by the OS. However, for cleanliness, if a reference to a spawned process is available, attempt to kill it. Since `adapter.execute()` is async and we cannot easily access the child process, the simplest approach is: set the `cancelled` flag, and if the adapter completes after cancellation, skip the result write.

**Execute adapter:**
```typescript
const startMs = Date.now();
let cancelled = false;

const cancelPath = getCancelPath(statePath, jobId);
const pollInterval = setInterval(() => {
  if (existsSync(cancelPath)) {
    clearInterval(pollInterval);
    cancelled = true;
    logger.warn('Cancel sentinel detected, exiting');
    process.exit(0);
  }
}, 1000);

try {
  const adapter = createAdapter(agent);
  const env = defaultHooks.buildAgentEnv(agentId, { ...process.env as Record<string, string> });
  const result = await adapter.execute(prompt, { cwd, env });

  clearInterval(pollInterval);

  if (cancelled) {
    process.exit(0); // cancel already handled status
  }

  // Write result file (JOB-04)
  const resultPath = getResultPath(statePath, jobId);
  mkdirSync(dirname(resultPath), { recursive: true });
  writeFileSync(resultPath, result.output, 'utf-8');

  // Save session if adapter returned one
  if (result.sessionId) {
    defaultHooks.saveSession(cwd, agentId, {
      agentId,
      adapterType: agent.adapterType,
      sessionId: result.sessionId,
      createdAt: new Date().toISOString(),
      updatedAt: new Date().toISOString(),
    });
  }

  // Update job to completed
  updateJob(statePath, jobId, { status: 'completed', endTime: new Date().toISOString() });
  logger.info('Job completed', Date.now() - startMs);
} catch (err) {
  clearInterval(pollInterval);

  if (cancelled) {
    process.exit(0);
  }

  // JOB-05, ERR-04: write error to job metadata
  const errorMsg = (err as Error).message ?? String(err);
  updateJob(statePath, jobId, { status: 'failed', endTime: new Date().toISOString(), error: errorMsg });
  logger.error(`Job failed: ${errorMsg}`);
  process.exit(1);
}
```
